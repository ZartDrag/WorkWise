# WorkWise

A Work Request Tracker built with ASP.NET Core 8 Web API, PostgreSQL and React + TypeScript.

- `backend/` – ASP.NET Core Web API (CQRS, EF Core + Dapper, PostgreSQL)
- `workwise-web/` – React + TypeScript frontend (Vite, Redux Toolkit / RTK Query, MUI)
- `db/` – Reference PostgreSQL schema
